# ENH-007 visual-regression manifest.
#
# One row per line, whitespace-separated, in this exact field order:
#   id  kind  FractalType  cx  cy  zoom  iters  color_mode  size
#
# - `id`            : row id; also the preset name written by `imgdiff gen-preset`.
# - `kind`          : CPU-reference map (mandelbrot|burning_ship|tricorn) for
#                     the optional CPU-vs-GPU cross-check (`CROSSCHECK=1`).
# - `FractalType`   : enum variant the app dispatches on (Mandelbrot2D|…).
# - `cx cy`         : view center (f64), matches `settings.center_2d`.
# - `zoom`          : view zoom (f64), matches `settings.zoom_2d`. Above 1e4 the
#                     shader engages its double-float path.
# - `iters`         : `settings.max_iterations`.
# - `color_mode`    : 2 = the 2D shader's grayscale iteration mode (`vec3(t)`),
#                     time-independent so screenshots are deterministic.
# - `size`          : capture window size, WxH physical pixels.
#
# This is intentionally line-based (not YAML) so `scripts/visual_test.sh` can
# parse it with a plain `while read` and no `yq`/`python` dependency.
#
# SCOPE NOTE: rows are kept at zooms the GPU renders with stable, detailed output.
# The double-float HP path degrades from ~1e4 (a 2026-07-18 GPU-vs-CPU-f64
# crosscheck showed per-pixel noise — the "pixelated" mid-zoom symptom — long
# before the 07-17 256x256 measurement suggested) and fully collapses above ~3e7
# (root-caused 2026-07-17: fast ~1.2 ms frame, no device-loss, but per-pixel
# coordinate precision collapses to one shared orbit → near-uniform image; naga's
# Metal two_prod EFT is intact, so the collapse is downstream Metal FTZ / sub-ULP
# lo-word loss). ENH-001 perturbation fixes this: the gate was lowered 2026-07-18
# from log2 24 (zoom ~1.6e7) to 13.3 (zoom ~1e4) so the CPU-BigFloat reference
# path covers the whole degraded band. The 1e8 golden below renders ~76 distinct
# gray values (vs the 3 of the pre-fix collapse) and is deterministic across runs
# (MAE 0.0, pixel-identical) via the deterministic `perturbation_max_iterations`
# budget. The reference orbit
# itself is cheap — ~1.5 ms single / ~7.5 ms for the 9× probe at 1e8, 91 bits
# (measured 2026-07-18); an earlier "~15-20 s" estimate was the pre-fix LOD churn
# (the orbit recomputed every frame because LOD's iteration_scale varied), not
# the per-orbit cost, and was resolved by the deterministic budget. Deep-zoom
# MATH correctness stays guarded by the CI-safe CPU teeth in
# `tests/reference_math.rs` (DF-vs-f64).
#
